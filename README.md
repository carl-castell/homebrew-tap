# carl-castell/homebrew-tap

Homebrew formulae by carl-castell.

## unroll

Copy only the new photos from your iPhone to a folder on a drive, and keep Apple Photos small by referencing them.

```sh
brew install carl-castell/tap/unroll
```

Homebrew builds it from source. See [carl-castell/unroll](https://github.com/carl-castell/unroll).

`Formula/unroll.rb` is updated automatically by the release workflow of the unroll repository.
